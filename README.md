# 🧠 Meu Primeiro Programa em C - Hello World

Este é o meu primeiro projeto em linguagem C, criado no Code::Blocks, com o clássico programa **"Hello, World!"**.  
É um pequeno passo no código, mas um grande passo na jornada como programador!

---

## 🚀 Objetivo

Familiarizar-se com:
- A estrutura básica de um programa em C
- O uso da IDE **Code::Blocks**
- O controle de versão com **Git e GitHub**

---

## 📌 O que o programa faz?

Este programa simplesmente imprime no terminal: Hello, World!


---

## 💻 Tecnologias utilizadas

- Linguagem C
- [Code::Blocks](http://www.codeblocks.org/) (IDE)
- Compilador GNU GCC
- Git e GitHub

---


## ⚙️ Como executar o projeto

### 🖥️ Com o Code::Blocks:

1. Abra o Code::Blocks  
2. Vá em **File > Open...** e selecione o arquivo `.cbp` do projeto  
3. Pressione **F9** para compilar e executar  

---

### 💡 Ou via terminal (Linux/Mac/WSL):

```bash
gcc main.c -o hello
./hello
```
